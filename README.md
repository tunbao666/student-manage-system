# 学生信息管理系统

一个基于 C++ 的命令行学生成绩管理系统，支持学生信息的增删改查、成绩统计分析与本地文件持久化。

---

## 一、项目简介

本项目使用 C++ 编写，采用「结构体数组 + 二进制文件」的方式管理学生数据。程序启动时从 `student.dat` 载入已有数据，运行过程中所有修改先保存在内存，仅在数据真正发生变化时写回文件。

界面为纯控制台菜单，包含 8 个功能项，覆盖学生管理的完整流程：录入、查询、修改、删除、排名、平均分、及格率统计。

---

## 二、功能列表

| 编号 | 功能 | 说明 |
|---|---|---|
| 1 | 添加学生信息 | 支持连续添加；学号自动查重，重复时可就地重新输入 |
| 2 | 删除学生信息 | 支持删除前二次确认，防止误操作 |
| 3 | 查找学生信息 | 按学号精确查找，输入 0 可取消 |
| 4 | 修改学生信息 | 按字段单独修改（姓名 / 性别 / 班级 / 三科成绩） |
| 5 | 显示所有学生信息 | 列出全部学生及三科成绩 |
| 6 | 查看单科成绩排名 | 支持高数 / C语言 / 数据结构 / 总分四种排名，同分并列 |
| 7 | 查看单科成绩平均分 | 计算指定科目或总分的平均分 |
| 8 | 查看及格人数与及格率 | 统计指定科目及格人数与及格率 |
| 0 | 退出系统 | 退出前自动保存未落盘的修改 |

学生信息包含：学号、姓名、性别、班级、高数成绩、C语言成绩、数据结构成绩。

## 五、数据文件说明

数据保存在程序工作目录下的 `student.dat` 中，采用**二进制直接写入结构体**的方式。

- 单条记录大小：`sizeof(Student) = 112` 字节
  （`int num` 4 + `name[50]` 50 + `gender[10]` 10 + `classes[20]` 20 + 对齐填充 4 + 三个 `double` 24）
- 最多支持 50 条记录（`MAX_STUDENTS_NUM`）
- 读取时会校验"文件大小是否能被 112 整除"，用于发现文件损坏或结构体变更导致的格式不匹配

> 注意：由于直接存储结构体内存，**如果修改了 `Student` 结构体的字段，旧的 `student.dat` 将无法读取**，需要删除数据文件重新录入。

## 六、关键技术点

### 1. 输入健壮性

所有用户输入都经过统一校验，不会因非法输入出现死循环或程序崩溃。

| 函数 | 作用 |
|---|---|
| `read_int()` | 读取整数。读取后清空整行，若整数后跟有非空白字符（如 `12abc`、`2.5`）则判定为非法并重新输入 |
| `read_score(prompt)` | 读取成绩，限定在 0~100 之间，非数字或超范围都会重新提示 |
| `read_gender(prompt)` | 读取性别，只接受完整的"男"或"女"，"男生"、"男abc"均会被拒绝 |
| `read_existing_index(prompt)` | 读取学号并返回下标，支持输入 0 取消操作，避免用户输错学号后无法退出 |

### 2. 数据持久化安全

保存不是直接覆盖原文件，而是采用「临时文件 + 原子替换」：

1. 先把全部数据写入 `student.tmp`
2. 逐条检查 `fwrite` 返回值，并检查 `fclose` 是否成功
3. **只有全部写入成功**，才用 `MoveFileExA` 把 `student.tmp` 替换为 `student.dat`，并带 `MOVEFILE_REPLACE_EXISTING | MOVEFILE_WRITE_THROUGH` 标志

这样即使在写入过程中程序崩溃或断电，原数据文件也不会被破坏。

加载时同样做了保护：先读入临时数组，**全部读取成功才提交**到正式数组，避免读到一半失败导致数据处于不一致状态。

### 3. 按需落盘（脏标记）

程序用一个全局标记 `data_dirty` 记录数据是否被修改：

- 添加 / 删除 / 修改成功时置为 1
- 主循环每轮结束检查，只有当它为 1 时才执行 `save_student()`
- 保存完成后清零

避免了"查看一下数据也写盘"这种无意义的磁盘操作，也避免了屏幕上反复刷"保存成功"的提示。

### 4. 排名并列处理

排序使用冒泡排序（降序），排序在一份副本上进行，不影响原始数据的存储顺序。

名次单独用一个 `ranks` 数组计算：与上一名分数相同时沿用上一名的名次，否则名次等于"位置 + 1"。这样得到的是标准的**跳号式排名**，例如：

```
排名：1  95分
排名：1  95分
排名：3  90分
排名：4  80分
```

### 5. 引用传参

`get_score(const Student& s, int subject)` 使用**常量引用**传参。`Student` 结构体有 112 字节，若按值传递，每次调用都要完整拷贝一份；而在冒泡排序中该函数会被调用约 `n × (n-1)` 次（50 人时约 2450 次），按值传递会产生约 270KB 的无意义内存拷贝。使用引用后这项开销降为零，同时 `const` 保证函数内不会修改原始数据。

## 七、编译与运行

### 编译

1. 用 Visual Studio 2022 打开 `student manage system.sln`
2. 确认工具栏的配置为 **Debug**、平台为 **x64**
3. 菜单「生成」→「重新生成解决方案」

### 运行

**必须从 Visual Studio 中按 F5 或 Ctrl+F5 启动。**

原因：程序使用相对路径 `student.dat`，文件位置相对于**当前工作目录**。从 VS 启动时工作目录是项目目录（`$(ProjectDir)`），能正确读到数据文件。

> 如果直接双击 `x64\Debug\` 目录下的 exe，工作目录会变成 `x64\Debug\`，程序找不到 `student.dat`，会以空列表启动，看起来像"数据全没了"。

### 首次运行

如果项目目录下没有 `student.dat`，程序会提示"暂无学生数据文件，将以空学生列表启动"，此时可直接使用功能 1 录入数据。

## 八、演示流程

建议按以下顺序演示，可以完整覆盖所有功能点和关键技术点：

1. **启动程序** —— 展示已有数据条数（"共读取 7 名学生"）
2. **功能 5** 显示所有学生 —— 展示数据完整列表
3. **功能 1** 添加一名学生 —— 演示学号查重、性别校验（先故意输错一次）、连续添加
4. **功能 4** 修改该学生的高数成绩 —— 演示分字段修改
5. **功能 6** 查看高数排名 —— 展示并列名次（同分同名次、后续跳号）
6. **功能 7** 查看平均分、**功能 8** 查看及格率
7. **功能 2** 删除该学生 —— 演示二次确认，先按 0 取消一次，再确认删除
8. **功能 0** 退出 —— 然后重新启动，验证数据已持久化

## 九、可扩展方向

| 方向 | 说明 |
|---|---|
| 数据存储格式 | 改为 CSV/JSON 等文本格式，便于查看和跨平台迁移；或在文件头加入版本号，支持结构体升级 |
| 数据结构 | 将定长数组改为 `std::vector` 或链表，解除 50 人的容量限制 |
| 查询能力 | 增加按姓名模糊查询、按班级筛选、按分数段筛选 |
| 统计分析 | 增加分数段分布柱状图、单科最高分/最低分、班级排名 |
| 界面 | 输出格式化为表格样式（表头 + 对齐），或移植为图形界面 |
